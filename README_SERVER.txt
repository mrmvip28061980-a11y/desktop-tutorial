حل مشكلة ظهور الطلبات للأدمن من أجهزة مختلفة

المشكلة الأصلية:
الطلبات كانت محفوظة في LocalStorage، لذلك كل جهاز يرى طلباته الخاصة فقط.

التعديل:
- الطلبات أصبحت تُحفظ على السيرفر في data/orders.json.
- أي شخص يدخل لوحة الإدارة من نفس الموقع والسيرفر يرى كل الطلبات.
- تغيير حالة الطلب (مقبول/مرفوض) ومسح الطلبات أصبحا مشترَكين بين الأجهزة.
- LocalStorage ما زال موجودًا كنسخة احتياطية محلية، لكن الحفظ الأساسي للطلبات أصبح على السيرفر.

التشغيل:
1) ثبّت Node.js.
2) داخل مجلد المشروع شغّل: npm install
3) شغّل: npm start
4) افتح الموقع على: http://localhost:3000

مهم جدًا:
إذا كان الموقع مرفوعًا على استضافة Static فقط (مثل رفع index.html مباشرة)، فلن يعمل /api/orders.
في هذه الحالة يجب نشر المشروع على استضافة تدعم Node.js، أو ربطه بقاعدة بيانات مثل Firebase/Supabase.
