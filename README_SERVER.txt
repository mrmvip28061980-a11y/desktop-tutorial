حل مشكلة ظهور الطلبات للأدمن من أجهزة مختلفة

هذه النسخة تستخدم Node.js + Express لتخزين الطلبات في data/orders.json، لذلك كل الأجهزة التي تفتح نفس الموقع من السيرفر ترى نفس الطلبات.

تسجيل الإدارة:
- كلمة المرور: mazen
- كلمة المرور لا تُرسل إلى Supabase؛ لا يوجد اعتماد على Supabase لتسجيل الدخول أو الطلبات.
- كلمة المرور تُستخدم فقط للتحقق من طلبات الإدارة على سيرفرك أنت.

التشغيل على VPS:
1) ثبّت Node.js.
2) ارفع مجلد المشروع كاملًا إلى الـVPS.
3) داخل المجلد شغّل: npm install
4) شغّل: npm start
5) افتح المنفذ 3000 أو اربطه بالدومين/Reverse Proxy.

مهم: GitHub Pages استضافة Static ولا تشغّل server.js. إذا كان الموقع على GitHub Pages فلن تعمل الطلبات المشتركة من هذا الإصدار حتى تستضيف المشروع على Node.js/VPS أو استضافة تدعم Node.js.
